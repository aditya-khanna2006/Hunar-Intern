# 📘 Assignment 2: Statistics – Mean Height Analysis

## 📌 Overview

This assignment was completed as part of the **Data Science Internship at HUNAR INTERN**.

The objective of this assignment was to analyze a historical dataset of UK male heights using **Python, Pandas, and Matplotlib**. The assignment focused on performing statistical analysis and visualizing data trends.

---

## 🎯 Objectives

- Create a dataset containing historical height records
- Convert the dataset into a Pandas DataFrame
- Calculate the mean height
- Visualize the data using a line chart
- Interpret the observed trend
